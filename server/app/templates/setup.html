This file contains a credential. The bundled config.toml holds your ingest token, which can write to this server. Keep it to yourself and do not commit it.

1 · Download

If this server sits behind Cloudflare Access, paste a service token and it will be baked in. The bridge cannot complete an interactive login on its own. Leave blank if you are not using Access.

2 · On the laptop

  1. Unzip it anywhere, then in that folder run: 
    powershell -ExecutionPolicy Bypass -File windows\setup.ps1
    Needs Python 3.11+ from python.org, with “Add to PATH” ticked.
  2. Un-pair the strap from the WHOOP phone app first — it only talks to one device at a time — then find it: 
    .\.venv\Scripts\whoop-bridge.exe scan
    Paste the address into address in config.toml.
  3. Check it can reach this server: 
    .\.venv\Scripts\whoop-bridge.exe test-endpoint
  4. Run it, and start it at logon: 
    .\.venv\Scripts\pip.exe install -e ".[tray]"
.\.venv\Scripts\pythonw.exe -m tray.whoop_tray

The bundle repeats all of this in START-HERE.md.

3 · Then

Come back to the dashboard. The strap hands over its stored ~14 days on the first connect, so history appears straight away. Recovery needs about a week of baseline; the Learning tab tells you what is still warming up.
